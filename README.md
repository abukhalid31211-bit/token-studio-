# Token Studio — نظام إدارة العقود الذكية 💎

واجهة أمامية متكاملة (Frontend) لنظام إدارة العقود الذكية، مبنية وفق مواصفات ملف التصميم بدقة:
سك العملات، نشر العقود والتحقق منها، الإرسال الفردي والجماعي، إدارة المحافظ، والشبكات المتعددة.

![Stack](https://img.shields.io/badge/React-19-61dafb) ![TS](https://img.shields.io/badge/TypeScript-5.8-3178c6) ![Vite](https://img.shields.io/badge/Vite-7-9d5cff)

## 🖥️ الشاشات المُنفَّذة

| الشاشة | المحتوى |
|---|---|
| **لوحة التحكم** | 4 بطاقات إحصاء بعدّ تصاعدي، جدول آخر المعاملات، رسم دائري للاستخدام اليومي |
| **محرك العقود** | معالج من 6 خطوات: القالب ← الإعداد ← الكود (محرر مع تلوين صياغي) ← الترجمة (محاكاة حية) ← النشر ← التحقق + confetti |
| **وحدة السك** | سك سريع (شرائح كميات، حد يومي، نافذة تنفيذ بعدّاد تأكيدات)، سك جماعي (CSV + جدول حي)، سجل السك مع تصفية وترقيم وتصدير |
| **وحدة الإرسال** | إرسال منفرد (تحقق عناوين، ماسح QR، دفتر عناوين، حلقة تقدم دائرية، إيصال)، إرسال جماعي، لوحة جانبية حية |
| **إدارة المحافظ** | المحفظة الرئيسية، استيراد بمفتاح خاص / عبارة استرداد (12/24 كلمة)، ربط MetaMask / TronLink / WalletConnect |
| **اختيار الشبكة** | 6 شبكات رئيسية + 3 اختبارية، لوحة RPC مع فحص زمن الاستجابة وإضافة RPC مخصص |
| **سجل المعاملات** | تصفية كاملة، تصدير CSV/JSON/PDF، نافذة تفاصيل، رسم بياني تحليلي (يومي/أسبوعي/شهري) |

## ⚙️ التقنيات

- **React 19** + **TypeScript 5.8** (TSX)
- **Vite 7** للبناء والتطوير
- **CSS خالص** بنظام تصميم كامل (Design Tokens) — دون مكتبات خارجية
- ألوان النظام: `#1a1a2e` خلفية، `#16213e` بطاقات، `#00d09c` اللون الأساسي
- خط **Cairo** العربي، اتجاه RTL كامل
- رسوم بيانية SVG مخصصة (دائري + أعمدة) دون اعتماديات

## 🚀 التشغيل محلياً

```bash
npm install
npm run dev      # خادم التطوير على http://localhost:5173
npm run build    # بناء الإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
```

## ▲ النشر على Vercel

المشروع جاهز للرفع على Vercel مباشرة — ملف `vercel.json` مُضمَّن:

1. ادفع المستودع إلى GitHub.
2. من [vercel.com/new](https://vercel.com/new) اختر المستودع.
3. سيكتشف Vercel إطار **Vite** تلقائياً:
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. اضغط **Deploy** — انتهى ✅

أو عبر سطر الأوامر:

```bash
npx vercel --prod
```

> التنقل بين الشاشات يعتمد على hash-routing (`#/mint`, `#/send`...) فلا يحتاج أي rewrites إضافية،
> ومع ذلك أُرفقت rewrites في `vercel.json` للتوافق الكامل.

## ✨ أبرز التفاعلات المنفذة حسب التصميم

- انتقالات الشاشات: انزلاق + تلاشٍ (150/200 مللي ثانية)
- النوافذ المنبثقة: تكبير من 0.8 مع خلفية معتمة، اهتزاز للنوافذ المقفلة، إغلاق بـ Escape
- Toast: 4 أنواع (نجاح/خطأ/تحذير/معلومة) — يمين أسفل، تتكدس وتتلاشى بعد 3 ثوانٍ
- اللوحات الجانبية تنزلق من اليمين (250 مللي ثانية)
- تحميل shimmer، أزرار بمؤشرات دوران، شريط تقدم علوي عند الإقلاع
- استجابة كاملة: شريط جانبي منزلق على الجوال، الجداول تتحول لبطاقات

> المشروع تجريبي (Demo) — كل عمليات الشبكة والسك محاكاة داخل المتصفح.
